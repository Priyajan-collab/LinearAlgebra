# 3D Vector Plotting with Custom Basis Transformation

This project uses Python and Matplotlib to plot 3D vectors with customizable basis matrices. The code demonstrates how to apply linear transformations to vectors by multiplying them with a basis matrix. This is helpful in visualizing vector operations, including changing the vector's basis and plotting them in 3D space.

## Features

- **Vector Class**: A class that defines vectors in 3D space.
- **Custom Basis Support**: Allows transformation of vectors using a custom basis matrix.
- **Plotting**: Plots vectors and their respective basis vectors in 3D using `matplotlib`.
- **Vector Operations**: Implements a dot product calculation between two vectors using the `__mul__` method.

## Dependencies

- `matplotlib`: Used for plotting the 3D vectors.
- `numpy`: Used for matrix and vector operations.
